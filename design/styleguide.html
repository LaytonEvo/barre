Brand & interface

Live — derived from Kelly’s logo

The design system for the Barre By Kelly site and members’ platform. The palette is derived from Kelly’s logo: the mark is a soft mint at #BBE7C4, hue 132°, kept unmodified as green 200. At 1.37:1 against white it can only ever be a surface, so darker steps of the same hue carry headings, links and buttons. Every pair below was measured against WCAG 2.2 with a script rather than estimated.

What the tokens guarantee

Accessibility

  • Focus is restyled, never removed — 2px green outline, 2px offset, set globally in tokens.css.
  • prefers-reduced-motion collapses every duration token to 1ms, so no component has to remember.
  • Tap targets 44px minimum, booking CTAs 48px.
  • Body text never below 16px, which also stops iOS zooming form fields on focus.
  • Status always carries text as well as colour.

Still missing

  • Venue photographs. The shoot is all Kelly outdoors or in a studio with a proper ballet barre — nothing shows either village hall, so those pages keep an honest empty state.
  • Kelly’s qualifications. The Person structured data omits credentials entirely while this is empty, and a test pins that.
  • Contact email, phone and Instagram. The footer and contact page hide these rows rather than printing a placeholder.
  • Real Google reviews. The homepage shows an empty state; no testimonial will be invented.
